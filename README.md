# FlowState SaaS Landing Page

## Visão Geral
FlowState é uma landing page premium desenvolvida para simular um produto SaaS real com foco em produtividade, UX e conversão.

## Objetivo
Construir um projeto visualmente profissional para consolidar habilidades em front-end e posicionamento de portfólio.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Recursos Implementados
- Design minimalista premium
- Responsividade
- SEO básico
- Navegação dinâmica
- Menu ativo
- Reveal animations
- Pricing section
- FAQ
- CTA estratégico

## Aprendizados
